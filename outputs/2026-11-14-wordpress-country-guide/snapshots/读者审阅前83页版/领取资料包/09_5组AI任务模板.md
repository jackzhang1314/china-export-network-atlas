# AI 外贸独立国家域名站群：5 组任务模板


### 1 / 确定首国与运营方式

> 我们提供【产品】，客户是【采购角色】，已有线索是【询盘 / 成交 / 渠道】。请按需求、交付、内容和回复能力比较【候选国家】，采用独立国家域名，先定一国一域。结合【每月更新任务 / 编辑人员 / 预算】，建议 WordPress 主力站或静态试点。输出国家、域名条件、当地采购问题、用词来源、页面清单与资料缺口，不编造市场或关键词数据。

### 2A / 主方案：创建可维护的 WordPress 国家站

> 请用已安装的 WordPress Builder Harness 配合 Codex，为【国家 / 当地语言 / 国家域名 / 产品线】建立独立项目。读取已批准资料，规划页面与后台字段，先交设计和预览。把产品、分类、文章及联系信息做成可维护内容。审核后发布，验证后台保存重开、前台显示、实际收件及 SEO 输出，交付源码、内容备份、账号归属和更新说明。

### 2B / 补充方案：创建静态国家站

> 请用 B2B Fast Builder 为【国家 / 语言 / 国家域名 / 产品线】创建独立静态站，使用该国 Cloudflare 项目。按批准资料生成完整 HTML 与对应 SEO 信息；先审核预览，再发布并验证询盘保存及收件，交付源码与更新、恢复说明。

### 使用方式

替换方括号，提供真实资料，并使用相应工具的完整安装包。2A 与 2B 按当前任务选一条；身份登录、域名购买和账户授权由本人完成。


### 3 / 生成可核对的小语种内容

> 根据产品主表与术语表，为【国家域名 / 目标语言】生成【页面类型】。保持型号、数值、单位、配置与已批准认证一致，按当地选型问题组织内容并起草标题、摘要。不补写未知起订量、交期、仓库和案例。输出目标语、中文核对版、产品编号、跨国对应页、术语与待确认项。

### 4 / 维护已有国家站

> 本次批准资料是【文件 / 版本】，涉及【产品 / 字段】。先读取各站实际内容，列出受影响域名、项目、页面与附件，保留既有 URL、同事新改动和市场专属内容。WordPress 更新对应记录，静态站修改内容文件并重新发布。先核对改动，再按授权逐站执行；记录结果、未完成项和恢复方法，不整站重导入旧资料。

### 5 / 检查能否交付给团队

> 请按【国家域名与项目清单】检查正式首页及深页、当地语言、参数、手机布局、附件、跨国切换、canonical、hreflang 与站点地图。WordPress 验证后台编辑、保存重开、草稿预览和前台输出；静态站验证一次更新发布。提交标记测试询盘并核对保存记录、实际收件、回复地址与来源。按域名记录已验证、失败、未覆盖和待处理项。

### 每次任务留下能接续的记录

资料与语言问题回到批准主表、术语表；当前网站内容、编辑入口、发布与恢复方式写进项目说明。下一次更新先看这些记录，再接着处理。
