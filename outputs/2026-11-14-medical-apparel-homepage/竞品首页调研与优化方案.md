# 医护服饰工厂：竞品首页调研与优化方案

调研日期：2026-11-14，Asia/Shanghai（UTC+08:00）。

本次围绕手术帽、医护服、白大褂及相关医用纺织品，选择面向品牌商、经销商和机构批量采购、提供 OEM／贴牌服务的网站。核对的是它们的首页正文；工厂身份、产能、交期等属于各站自述，没有进行企业实地核验。网站出现某个模块，也不代表该模块已经被证明能提高询盘转化。

## 2. 对现有示意图的判断

现有版本已经有产品分类、工厂介绍、车间、定制、质检、采购流程和 FAQ。需要完善的是采购信息的具体程度，以及工厂信息的真实性。继续增加同类小卡片会使版面更拥挤。

| 内容 | 当前缺口 | 本轮处理 |
| --- | --- | --- |
| 工厂证据 | 有工厂图片位置，但图片是 AI 示意，缺少真实工厂资料 | 保留并放大工厂、裁剪和车间展示；正式使用时换成实拍，补企业名称、所在地及可核实资料 |
| 面料与版型 | 只有“Fabric & Color”等概括标签 | 增加成分／克重／手感、弹性／回弹／版型、颜色／洗护三个选择方向和询问面料样卡入口 |
| 首次订单条件 | 没有集中交代数量、打样、生产和运输怎样确认 | 增加四项订单准备说明；不填写未经确认的 MOQ、样品费和交期数字 |
| 样品确认与复购 | 原来主要画了流程箭头 | 增加样品评审内容，以及后续订单应核对面料、尺寸、颜色和包装的说明 |
| 采购资料入口 | 缺少明确下一步 | 增加询问产品目录、面料样卡和尺寸表的入口；这些是设计中的咨询入口，不是假装存在的下载文件 |
| FAQ 与询盘 | 页面末端被压缩，字号、间距和表单比例失衡 | 底部单独按大区块设计；FAQ 左、表单右，页脚独立放在其下方 |

真实客户项目、工厂审核文件、检测报告和证书可以继续补充，但要先有对应资料和展示授权。当前不生成虚构客户案例、评价、客户 Logo、认证图标或产能数字。代表款式的型号、尺码和具体面料参数也应以实际产品为准。

## 3. 优化后的首页顺序

1. 工厂身份首屏：明确产品与批量采购对象。
2. 工厂介绍与大幅车间展示：厂房、裁剪、缝制与整理。
3. 产品系列：保留八类产品，手术帽款式作为补充说明。
4. 面料与版型选择：提供采购判断所需的信息。
5. 定制与打样：版型、口袋、印绣、标签、包装、样品评审。
6. 质检与复购：说明检验参照以及下一次订单的确认内容。
7. 订单准备与采购资料：数量、样品、排产、包装运输，以及目录／样卡／尺寸表咨询。
8. 左侧 FAQ、右侧询盘表单。
9. 独立页脚。

“服务谁”的内容融入首屏和定制区；包装、出货融入质检及订单准备。这样保留信息，同时减少相邻的小条带和重复标题。

## 4. 底部布局

- 左右两栏之间留出明显空隙，FAQ 标题在左栏问题列表上方。
- 六个问题只展开第一个，其余按折叠状态呈现。
- 右侧表单保留姓名、工作邮箱、公司、产品、数量、需求描述和附件入口；只把姓名与邮箱标为必填。
- 公司、需求细节和参考文件可以在后续沟通中补全。
- 不在表单区域叠加客户 Logo、生产流程、产品图或第二个促销横幅。
- 表单完整结束后，再进入独立深色页脚。

落地网页时可按桌面内容宽度约 1200–1280px、区块上下留白约 96–120px、双栏间隔约 64–80px、输入框高度约 48–56px、FAQ 行高约 72–88px 作为起点，再结合实际文案调整。这些是设计建议，不是已实施的网站 CSS 参数。
