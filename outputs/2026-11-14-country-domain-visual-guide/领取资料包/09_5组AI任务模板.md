# AI 外贸独立国家域名站群：5 组任务模板


### 1 / 确定首个国家与页面范围

> 我们计划采用独立国家域名站群，提供【产品】，主要客户是【采购角色】，已有线索是【询盘 / 成交 / 渠道】。请读取资料，按需求、交付、内容、回复能力与域名注册条件比较【候选国家】。先选一国一域，未知项单列，不编造市场和关键词数据。输出：首站国家、候选国家后缀、注册条件待核项、主力产品、当地采购问题与用词来源、页面清单、资料缺口与负责人确认事项。

### 2 / 用 Skill 创建可验收的静态站

> 请按已安装的建站 Skill，为【国家 / 语言】在【已确认的国家域名】下创建【产品线】独立静态站，使用该国家专属的 Cloudflare 部署项目。按批准资料制作首页、分类、产品、应用、公司、服务和联系页，未知事实单列。产品页面网址、首选地址和站点地图使用该国家域名，语言切换连接其他国家的对应页，询盘带上域名与产品来源。先交结构和预览，审核后发布、验证实际收件，交付源码、域名配置、发布和恢复说明。

### 使用方式

替换方括号内容，把资料文件放到工具能读取的项目目录。先确认工具能访问项目，并遵循该 Skill 的安装和使用说明。遇到身份登录、域名购买或第三方授权时，使用自己的账号完成。

> 本册提供案例与任务模板。视频配发的建站 Skill 应使用其对应安装包与说明；这里没有假定一个未经确认的下载地址或版本。


### 3 / 生成可核对的小语种内容

> 请根据产品主表与术语表，为【国家域名 / 国家 / 目标语言】生成【页面类型】。保持型号、数值、单位、配置与已批准认证一致，按当地买家的选型问题组织内容，并提供自然的当地标题与摘要。不要补写未提供的最低起订量、交期、仓库和客户案例。输出目标语、中文核对版、对应产品编号与跨国页面、术语说明及待确认项。

### 4 / 批量维护已有国家站

> 批准的新资料是【文件 / 版本】，变化涉及【产品与字段】。请列出受影响的国家域名、部署项目、页面、附件和语言版本，区分共同参数与市场专属内容。保留既有 URL 及未涉及内容。生成逐站预览并等待内容审核，之后按国家域名分别发布，检查代表页和询盘路径，逐域记录变更与恢复版本。

### 5 / 检查网站能否交付

> 请逐站检查【国家域名与项目清单】：国家域名上的首页与产品深页、语言和参数、手机布局、附件、实际收件、回复地址、域名来源字段、跨国切换、canonical、hreflang 与站点地图。结果按域名分为已验证、失败、未覆盖，标明网址和时间。测试询盘使用明确标记。输出问题优先级、修复结果与仍需人工处理事项。

### 把输出变成团队习惯

每个任务都要求输出“改了什么、依据什么、怎样检查”。资料缺口回到产品主表补齐；语言问题回到术语表；发布问题回到项目使用说明。下一次更新就能复用处理结果。
