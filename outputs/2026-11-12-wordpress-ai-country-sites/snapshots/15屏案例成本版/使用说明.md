# 精准询盘视频 · 可视化拍摄素材

双击 `精准询盘·可交互拍摄演示.html`，用 Chrome、Edge 或 Safari 打开。HTML 自带全部文字、图形、动效与讲稿，不需要安装，也不依赖网络加载素材。自动播放无配音，时码沿用现有 3 分 55 秒口播安排，实际录制请先试读。

## 拍摄时怎么用

1. 打开演示后，第一屏就是完整逻辑链。
2. 按 `F` 全屏，按 `H` 隐藏控制栏。
3. 边讲边按 `→`，每次展开一个重点；本屏讲完继续按即可进入下一屏。
4. 自动演示用空格播放或暂停，播到 03:55 自动停住。拖动进度条可定位。
5. 按 `H` 或双击画面恢复控制栏，按 `O` 选择任意一屏。

| 操作 | 快捷键 |
| --- | --- |
| 下一步 / 上一步 | → / ← |
| 直接下一屏 / 上一屏 | PageDown / PageUp |
| 自动播放 / 暂停 | 空格 |
| 本屏回到开始 / 本屏全部展开 | R / A |
| 全屏 / 隐藏控制栏 | F / H |
| 选屏 / 讲稿与研究依据 / 10 组案例库 | O / N / C |
| 第一屏 / 最后一屏 | Home / End |
| 关闭弹层 / 退出净屏 | Esc |

翻页器若发送 PageDown，会直接换屏；发送右方向键会逐步展开。切到其他浏览器标签页时自动暂停。触屏可左右滑动。

- `图片/`：15 张 PNG，全部为 1920 × 1080，画面已完整展开，无播放器控制栏，可直接插入剪辑或其他演示工具。

- 案例沿用本项目 2026 年 11 月研究快照，本次没有重新抓取全部网站，补读了三一欧洲德语挖掘机分类与 Google 页面体验、AI 内容指南。47 个根域说明高置信运营关联，不表示同一法律实体或已验证获客收益。

- 原研究报告通过相对路径连接，保留当前项目目录可打开；单独拷走素材包后，演示与内置备注仍可离线使用，原报告相对链接需要原目录，公开出处链接需要联网。

## 本次加强的讲解逻辑

贯穿情景是「德国经销商想采购 3 台 2 吨小型挖掘机」。搜索阶段围绕品类、吨位与厂家，进站后看配置与供货能力，再提交数量和交货地。不要把企业内部型号当成新买家搜索的前提。

第 10 屏可调整单站报价和网站数量。2–3 万元是讲师提供的纯定制报价情景，并非行业均价，也未假定 AI 方案具体售价或成本。第 11–13 屏拆解 Codex 配合专业 Skill 如何协助重复开发、资料录入、翻译初稿、修改和检查。性能由真实测试验收，不从建站工具名称推断。

案例库有 10 组：三一、徐工、杭叉、海天、NOARK、福田、MAXUS、宇通、包装关联网络、RIPPA。打开会自动暂停，点击网址可到原始页面。案例库用于延伸讲解，不纳入主片 03:55 时码。
