# 精准询盘视频 · 可视化拍摄素材

双击 `精准询盘·可交互拍摄演示.html`，用 Chrome、Edge 或 Safari 打开。HTML 自带全部文字、图形、动效与讲稿，不需要安装，也不依赖网络加载素材。自动播放无配音，时码沿用现有 3 分 55 秒口播安排，实际录制请先试读。

## 拍摄时怎么用

1. 打开演示后，第一屏就是完整逻辑链。
2. 按 `F` 全屏，按 `H` 隐藏控制栏。
3. 边讲边按 `→`，每次展开一个重点；本屏讲完继续按即可进入下一屏。
4. 自动演示用空格播放或暂停，播到 03:55 自动停住。拖动进度条可定位。
5. 按 `H` 或双击画面恢复控制栏，按 `O` 选择任意一屏。

| 操作 | 快捷键 |
| --- | --- |
| 下一步 / 上一步 | → / ← |
| 直接下一屏 / 上一屏 | PageDown / PageUp |
| 自动播放 / 暂停 | 空格 |
| 本屏回到开始 / 本屏全部展开 | R / A |
| 全屏 / 隐藏控制栏 | F / H |
| 选屏 / 讲稿与研究依据 | O / N |
| 第一屏 / 最后一屏 | Home / End |
| 关闭弹层 / 退出净屏 | Esc |

翻页器若发送 PageDown，会直接换屏；发送右方向键会逐步展开。切到其他浏览器标签页时自动暂停。触屏可左右滑动。

## 配图与资料

- `图片/`：12 张 PNG，全部为 1920 × 1080，画面已完整展开，无播放器控制栏，可直接插入剪辑或其他演示工具。
- `讲稿 / 依据`：每屏内置对应口播、案例说明和出处。
- 案例沿用本项目 2026 年 11 月研究快照，本次没有重新抓取全部网站。47 个根域说明高置信运营关联，不表示同一法律实体或已验证获客收益。
- 询价、收件和页面结构为明确标记的教学示意。此 HTML 不发送邮件，也不代表真实表单收件通过。正式录制收件演示时，使用自有站实际提交与确认。
- 原研究报告通过相对路径连接，保留当前项目目录可打开；单独拷走素材包后，演示与内置备注仍可离线使用，原报告相对链接需要原目录，公开出处链接需要联网。
- 已在本机 Chrome 检查交互、全屏、离线与三种画布尺寸；其他浏览器及实际显示屏拍摄尚未实测。
