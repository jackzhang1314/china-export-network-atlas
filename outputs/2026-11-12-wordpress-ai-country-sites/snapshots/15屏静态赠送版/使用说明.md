# 精准询盘视频 · 可视化拍摄素材

双击 `精准询盘·可交互拍摄演示.html`，用 Chrome、Edge 或 Safari 打开。HTML 自带全部文字、图形、动效与讲稿，不需要安装，也不依赖网络加载素材。自动播放无配音，时码沿用现有 3 分 55 秒口播安排，实际录制请先试读。

## 拍摄时怎么用

1. 打开演示后，第一屏就是完整逻辑链。
2. 按 `F` 全屏，按 `H` 隐藏控制栏。
3. 边讲边按 `→`，每次展开一个重点；本屏讲完继续按即可进入下一屏。
4. 自动演示用空格播放或暂停，播到 03:55 自动停住。拖动进度条可定位。
5. 按 `H` 或双击画面恢复控制栏，按 `O` 选择任意一屏。

| 操作 | 快捷键 |
| --- | --- |
| 下一步 / 上一步 | → / ← |
| 直接下一屏 / 上一屏 | PageDown / PageUp |
| 自动播放 / 暂停 | 空格 |
| 本屏回到开始 / 本屏全部展开 | R / A |
| 全屏 / 隐藏控制栏 | F / H |
| 选屏 / 讲稿与研究依据 / 10 组案例库 | O / N / C |
| 第一屏 / 最后一屏 | Home / End |
| 关闭弹层 / 退出净屏 | Esc |

翻页器若发送 PageDown，会直接换屏；发送右方向键会逐步展开。切到其他浏览器标签页时自动暂停。触屏可左右滑动。

## 配图与资料

- `图片/`：15 张 PNG，全部为 1920 × 1080，画面已完整展开，无播放器控制栏，可直接插入剪辑或其他演示工具。

- 案例沿用本项目 2026 年 11 月研究快照，本次没有重新抓取全部案例网站；补读三一欧洲德语挖掘机分类、Google 指南，以及 Cloudflare 静态托管费用与计划限制。47 个根域说明高置信运营关联，不表示同一法律实体或已验证获客收益。

- 原研究报告通过相对路径连接，保留当前项目目录可打开；单独拷走素材包后，演示与内置备注仍可离线使用，原报告相对链接需要原目录，公开出处链接需要联网。

## 当前讲解顺序

先看三一、徐工、杭叉真实案例 → 介绍本次赠送的静态外贸站建站 Skill → 分清静态站与 WordPress 两条路线 → 用德国经销商采购小挖解释当地语言与国家站 → 讲 AI 降低重复建站成本 → 研究竞品 → 验证精准询盘。

- 第 3 屏明确赠送的是纯静态建站方案，部署目标为 Cloudflare。第 5 屏介绍另一条 WordPress AI 路线。
- 第 4 屏的 ¥0 只指符合免费计划限制的纯静态托管，域名、AI 工具、表单、邮件和维护按实际服务另算。Cloudflare 静态资源请求免费，函数另有计费与用量规则。
- 第 8 屏保留可调预算演算。每站 2–3 万元是讲师提供的纯定制报价情景，不是市场均价，不据此宣称固定节省比例。
- 贯穿情景仍是德国经销商采购 3 台 2 吨小挖。搜索产品与厂家，进站判断配置与交付，再提交数量和交货地。
- 第 9–11 屏说明 Codex 配合专业 Skill 如何协助重复工作与内容起草，性能和询盘路径要以实测验收。
- 10 组案例库仍可按 C 打开，打开时暂停主片，延伸讲解不计入 03:55。
- 赠送计划来自讲师说明。本次只修改视频素材，没有制作、测试或发布实际 Skill 包，未填入虚构领取链接。正式发布时使用讲师真实的领取方式。
