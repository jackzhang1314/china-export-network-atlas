# AI 外贸国家站：5 组任务模板


### 1 / 确定首个国家与页面范围

> 我们提供【产品】，主要客户是【采购角色】，现有市场线索是【询盘 / 成交 / 渠道】。请读取我提供的公司和产品资料，比较【候选国家】。按需求证据、交付能力、资料完整度、回复能力和维护投入，给出首站建议。未知项单列，不编造市场规模或关键词数据。输出：目标国家、主力产品、页面清单、资料缺口、负责人需要确认的事项。

### 2 / 用 Skill 创建可验收的静态站

> 请按本项目已经安装的建站 Skill，为【国家 / 语言】创建【产品线】外贸网站，并准备部署到我的 Cloudflare 项目。使用已批准资料；缺少的认证、交期、仓库与客户信息列为待确认。页面包括首页、分类、产品、应用、公司、交付服务和联系。保留独立语言 URL、产品编号与询盘来源字段。先给结构和预览，审核后完成发布与收件检查，并交付源码、发布说明和恢复方式。

### 使用方式

替换方括号内容，把资料文件放到工具能读取的项目目录。先确认工具能访问项目，并遵循该 Skill 的安装和使用说明。遇到身份登录、域名购买或第三方授权时，使用自己的账号完成。

> 本册提供案例与任务模板。视频配发的建站 Skill 应使用其对应安装包与说明；这里没有假定一个未经确认的下载地址或版本。


### 3 / 生成可核对的小语种内容

> 请根据产品主表与术语表，生成【目标语言】的【页面类型】。保持型号、数值、单位、配置与已批准认证一致。按【国家】买家的选型问题组织内容。不要补写未提供的 MOQ、交期、当地仓库和客户案例。输出目标语、中文核对版、术语选择说明及待确认项。

### 4 / 批量维护已有国家站

> 批准的新资料是【文件 / 版本】，变化涉及【产品与字段】。请先列出受影响的国家、页面、附件与语言版本，区分共同参数和市场专属内容。保持已有 URL 与未涉及的页面内容。生成修改预览并等待内容审核，之后发布、检查代表页和询盘路径，记录变更与恢复版本。

### 5 / 检查网站能否交付

> 请检查【网站 / 项目】：手机和电脑页面、产品与附件、链接、表单错误提示、实际收件、回复地址、来源字段、语言切换、规范网址、语言版本声明和站点地图。把结果分为已验证、失败、未覆盖，并标明检查网址与时间。测试询盘用清楚的测试标记。输出问题优先级、修复结果与仍需人工完成的事项。

### 把输出变成团队习惯

每个任务都要求输出“改了什么、依据什么、怎样检查”。资料缺口回到产品主表补齐；语言问题回到术语表；发布问题回到项目使用说明。下一次更新就能复用处理结果。
