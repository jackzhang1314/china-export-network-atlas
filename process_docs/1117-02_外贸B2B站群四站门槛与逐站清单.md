# 外贸 B2B 站群四站门槛与逐站清单

完成于 2026-11-17 16:31（Asia/Shanghai，UTC+8）。本轮由用户要求企业页清楚列出站群网站，并规定每家企业至少超过三个网站触发。

## 收录范围

- 每组为一家企业或一个集团，至少有四个独立注册域，且每个域有可核的业务内容、用途和运营主体证据。同域子域、目录和语言版合计一次。纯跳转域、第三方店铺和经销商自有域不计入。
- 收录 17 组企业站群及 104 个注册域，覆盖 17 个研究品类中的 11 个，保留 18 项出口指标。手机、纺织纱线与面料、服装、鞋靴、箱包和玩具六个品类显示待核实状态，并提供出口与采购研究。
- 三一 22 站，杭叉 15 站，裕同 4 站等。三一从 11 月 12 日项目的公开研究重新筛查，三一南非入口本轮仅显示维护页，杭叉泰国入口显示停放状态，均未计入。本轮不计入只能证明存在商业合作或无法确认所属主体的站。

## 页面与交付

- 品类页先列已核实企业及全部域名，案例索引可用域名筛选并直接访问企业站点。企业页第一节完整列出原网址、市场、语言、用途、运营方、访问备注及归属出处。站点 CSV 按域一行，与网页从同一份数据生成。
- 发布项目为 `sites/china-export-network-atlas/`。当前案例数据入口是 `content/networks.mjs`，三一、装备及其他制造业的站点分文件维护。`src/build.mjs` 与 `src/check.mjs` 检查同组独立域去重、最低站数、归属链接及页面行数。
- [Cloudflare 站群目录](https://china-export-network-atlas.1314jackzhang.workers.dev/cases/) 已切换到 `30c5a791-ab7e-442b-91c1-96a70c69d4e7`。上一版线上版本为 `93395221-fe49-4f75-a9c3-4fa9a19feeed`，上一版的源码和静态站 ZIP 仍可在原位置取用。
- 新 ZIP 为 `output/site/中国外贸B2B站群案例库_四站门槛版_源码与静态站.zip`，SHA-256 为 `40b92cadd413193b638cc9e69b2167388bfa5989a33d71814e448c36016845ff`。交付包只纳入本版构建、内容、配置和静态文件。

## 验证与遗留

- `npm run check`、脚本语法检查、Wrangler 静态部署预检、ZIP 自检和解压重建通过。检查覆盖 39 个 HTML 文件、其内部链接和锚点、案例全量域名与归属链接、两份 CSV。
- Cloudflare 上 44 个页面和资源逐字节符合本地构建。不存在的路径和已移除的旧案例路径返回 HTTP 404。
- 在本机和公网用 Chrome 检查了全量可见的公司域名、企业证据、域名检索、共享查询条件、筛选清除、无案例状态、CSV 下载及 320/390 像素布局。公网首轮在样式加载前读取宽度，改为在样式加载后读取并复测通过，网站部署内容未动。
- 对 167 个不同企业和证据网址执行 HTTPS 直连，最终批次 159 个返回 200、3 个返回 403、5 个连接未完成。104 个站点入口里有 100 个在该批次返回同域的 200。中联土耳其在另一轮同域返回 200。联想美国企业产品入口、MAXAM 和晶科欧洲的测试环境直连受限，按企业公开页面及归属来源核对，案例与 CSV 标注。访问可随网络与站点变更。
- 网站只记录本轮查实的入口，仍有六个品类缺符合门槛的样本。没有企业后台数据可用于比较自然流量、询盘或订单。
