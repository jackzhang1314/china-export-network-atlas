# 三一重工全球多语言站群研究

记录于 2026-11-12T02:46:15+08:00，北京时间。

## 触发及成果

用户要求用多轮迭代搜索调查三一重工全球多语言站群、域名与不同运营主体，并补入既有课程案例。

- 150 条公开检索式、57 批公开检索及来源打开、691 条直接核验记录、677 个去重候选和 331 个不同域名或子域主机。
- 101 个判定对象，含 25 个高置信集团与业务独立根域、24 个经销及渠道站点或子域。其余为产业、平台、跳转、待核、旧入口或排除。
- 国际主站 12 种语言有页面声明及 200 直接证据，另确认集团业务页面上的日语、波兰语、荷兰语与土耳其语，合计至少 16 种。核对 SY215C 跨域深页及印度、波兰、大洋洲、法国、加拿大典型域名。
- 在原课程 HTML 增加三一章节和可展开的官网及渠道索引，保留编辑前快照。原始工业研究口径和计数维持对应取证版本。
